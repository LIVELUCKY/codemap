IMPORTANT: search code with these tools, never with grep, rg, find or by reading files to look around. One call searches {repositories} at once and skips gitignored files. codemap_lookup takes a name, part of a name, a file name, or a few words, and answers where it is, with its code when it has one definition; codemap_uses shows who uses a name; codemap_impl what extends or implements a type; codemap_grep finds exact text in every repository at once. Fall back to other tools only when an answer did not have what you need.
